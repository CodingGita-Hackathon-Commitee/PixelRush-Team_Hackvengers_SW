# Contributing to SurplusLink

Thanks for helping improve SurplusLink. This repository is a static HTML and
CSS prototype for a surplus-food coordination experience.

## Getting started

1. Fork the repository and clone your fork.
2. Open the project in your editor.
3. Preview `index.html` in a modern browser. For changes involving relative
   assets or page navigation, use a local static HTTP server.
4. Make and review your changes in the browser at desktop, tablet, and mobile
   viewport sizes.

There is currently no package manifest, build step, or automated test command.
Do not assume one is available.

## Making changes

- Keep changes focused on the issue or feature being addressed.
- Preserve the existing static HTML/CSS approach unless a change is discussed
  and agreed on first.
- Keep page content, images, and local asset paths consistent with the
  surrounding experience.
- Prefer semantic HTML, accessible names for interactive controls, and
  responsive layouts.
- Do not add dependencies, credentials, private data, or generated build
  artifacts without a clear need.
- If a change affects a page visually, include before-and-after screenshots in
  the pull request when practical.

## Before opening a pull request

- Preview the affected page in a browser.
- Check the layout at desktop and narrow mobile widths.
- Confirm that links, local images, and styles load as expected.
- Review the diff and remove unrelated changes.
- Describe what changed, why it changed, and how it was checked.

## Pull requests

Open a pull request against the repository's default branch. Keep the title
descriptive, link related issues when applicable, and call out any known
limitations. Maintainers may request revisions before merging.
