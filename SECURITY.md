# Security Policy

## Scope

SurplusLink is currently a static frontend prototype. This repository does not
document a production service, backend, or supported deployment environment.

## Reporting a vulnerability

Please do not publish credentials, personal information, or details of an
unfixed vulnerability in a public issue. Use GitHub's private vulnerability
reporting feature for this repository if it is enabled. Otherwise, contact a
repository maintainer privately through the contact method provided by the
repository owner.

When reporting, include the affected file or page, the impact, and clear
reproduction steps. Avoid including real user or organization data.

## Supported versions

There are no versioned releases or support commitments documented at this time.
